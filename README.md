# Hung Jury

A pass-the-device courtroom bluffing game for 3 to 10 adults. One player secretly knows the truth, one is fixing the jury, and everyone else has a few minutes to argue their way to a verdict. 37 cases, absurd and serious.

Play it at https://chrisvonderau.github.io/hung-jury/ on an iPhone, iPad or Mac. The whole game is the single `index.html` file; names and played cases are remembered on the device only.
